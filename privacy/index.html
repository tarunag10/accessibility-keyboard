Privacy Policy

Accessibility Keyboard is designed to provide a clearer typing experience without collecting personal data.

Data Collection

Accessibility Keyboard does not collect, sell, share, or transmit personal data. The app does not require an account and does not include advertising or third-party analytics.

Keyboard Input

The keyboard extension is configured with RequestsOpenAccess = false. This means the keyboard does not request the expanded full-access keyboard mode. Typed content is handled locally through iOS keyboard extension APIs and is not uploaded by this app.

Local Settings

Keyboard preferences such as profile, theme, layout, key size, spacing, haptics, and typing behavior are stored locally on the device or in the app group's local container so the host app and keyboard extension can share settings.

App Store Privacy Summary

  • Data collected: None
  • Data used to track you: None
  • Data linked to you: None
  • Data not linked to you: None
